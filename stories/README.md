# Your stories go here

This folder is your AI's only source of knowledge. Everything it learns comes from the stories you put here.

- Save each story as a `.txt` file in this folder (subfolders work too).
- One file can hold many stories if you separate them with a line containing only `<|endofstory|>`.
- Or run `python story.py feed` and paste a story straight into the terminal.

Then run `python story.py train`.
